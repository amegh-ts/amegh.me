The product

ContextTravel booking, Aluva

Club Travalet sells travel online: tour packages, memberships, hotel stays and custom holidays. The portal is where people discover a trip and book it.

I joined in June 2024 as a Web Developer and stayed until December 2025, when I moved to Oppam.

The portal frontend

FrontendDiscovery to booking

I started by building responsive pages in Next.js and Tailwind CSS. As I took on more, I owned the portal's frontend as a whole: the path from finding a package to booking it.

SEO, built in

SearchFrom the start

People look for trips on Google, so a package page only works if search engines can read it. I set up the portal's SEO as part of the frontend rather than as an afterthought:

  • Server-side rendering, so every page reaches search engines as complete HTML.
  • Page metadata: titles, descriptions and social previews for each page.
  • Schema markup, so search engines understand what a page describes.
  • Sitemaps, so crawlers can find every page.

The same habits run through this site. A post on Next.js SEO lessons from Club Travalet is planned for the blog.
