What it is

ContextTask management and collaboration

UniTide is a task management and team collaboration app. A team creates projects, breaks them into tasks, assigns people and tracks progress, and talks about the work in the same place it happens.

I built it as a personal project to work through a full product surface in one Next.js codebase: many connected modules, roles and permissions, and forms that stay valid from the browser to the database.

Modules

In the appProjects to timesheets
  • Projects: create and edit them, assign team members, and track status and timeline, with separate views for active and completed projects.
  • Tasks: assign them to people, move them through pending, in progress and completed, and set due dates and priority.
  • Teams and members: create teams, add and remove members, and link teams to projects.
  • Comments and chat: comments on tasks and projects, plus chat between members.
  • Calendar and notifications.
  • Reports with a timesheet view.
  • Activity log: task updates, logins and project edits, recorded per user and project.
  • Tags, workspace settings and session management.

Accounts and access

SecurityRoles throughout

Two roles, admin and user, control what each person can see and do, and restricted pages lead to a clear "forbidden" page. Accounts use hashed passwords (bcrypt) and token-based sign-in, with a forgot-password flow that sends a reset link.

Data and forms

ArchitectureOne codebase
  • Next.js API routes serve the app, with MongoDB models in Mongoose for users, projects, tasks, teams, chats, events, notifications and logs.
  • TanStack Query handles server state, so lists and details refresh when the data changes.
  • React Hook Form and Zod validate every form end to end, so the same rules apply in the browser and on the server.
  • shadcn/ui and Tailwind CSS keep the interface consistent across modules.
